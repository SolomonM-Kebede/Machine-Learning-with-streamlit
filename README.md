# Machine-Learning-with-streamlit
In this project, I used the fake.csv file to train the machine and test what kind of news it is—whether it is BS, bias, conspiracy, or something else. This project is unique because I used Streamlit for a better UI experience. 
Anyone can run the streamlit web app with the following link and upload the file to see the project result. 
https://fakenewsidentifier.streamlit.app
