# Machine-Learning-with-streamlit
In this machine learning project, I used a fake.csv file to train  and test to determine what kind of news it is—whether it is BS, bias, conspiracy, or something else. This project is different from the previous one because I used Streamlit for a better UI experience. 
Anyone can run the streamlit web app with the following link and upload the file to see the result of the code. 
https://fakenewsidentifier.streamlit.app
